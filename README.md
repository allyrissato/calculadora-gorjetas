# 💰 Calculadora de Gorjetas

Este é um projeto simples de uma **calculadora de gorjetas**, desenvolvido com HTML, CSS e JavaScript puro. O objetivo é calcular automaticamente o valor da gorjeta com base na conta, qualidade do serviço e número de pessoas.

---

## 🚀 Demonstração

O usuário informa:

* Valor total da conta
* Qualidade do serviço
* Número de pessoas para dividir

E o sistema retorna:

* Valor da gorjeta total
* Valor por pessoa (se houver divisão)

---

## 🧠 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

---

## ⚙️ Como funciona

1. O usuário preenche o valor da conta
2. Seleciona a qualidade do serviço (percentual da gorjeta)
3. Informa quantas pessoas vão dividir a conta
4. O JavaScript realiza o cálculo:

```
gorjeta = (valor da conta × porcentagem do serviço) / número de pessoas
```

5. O resultado é exibido na tela

---

## 📌 Exemplo de uso

* Conta: R$ 100
* Serviço: 20%
* Pessoas: 2

👉 Resultado:

* Gorjeta total: R$ 10.00 por pessoa
